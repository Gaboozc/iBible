# MyScriptum

> *Una plataforma de estudio bíblico profundo que integra contexto histórico riguroso, análisis textual y reflexión espiritual.*

---

## 🎯 Propósito

**MyScriptum** no es otra app de lectura bíblica. Es una herramienta de **formación bíblica seria** que:

- ✅ Coloca el **contexto histórico** antes del texto
- ✅ Conecta capítulos con **eventos reales** (imperios, reyes, profetas)
- ✅ Profundiza en **etimología hebrea/griega**
- ✅ Muestra **conexiones intertextuales**
- ✅ Guía reflexión con **preguntas socrátivas**
- ✅ Completamente **bilingüe** (español e inglés)

## 🏗️ Stack Tecnológico (estado actual)

```
Frontend:  Next.js 16 + React 19 + TypeScript + Tailwind CSS v4
State:     zustand (progreso local) + swr
Grafos:    @xyflow/react (red de conexiones)
Backend:   Next.js API Routes leyendo JSON de disco (sin BD)
Storage:   localStorage (persistencia cliente, prefijo myscriptum:)
Hosting:   Vercel
```

> Nota: Prisma / PostgreSQL / NextAuth aparecen en versiones antiguas de este README pero
> no están instalados. La persistencia real de usuario es 100% localStorage. Ver
> `ROADMAP.md` para el plan de backend.

## 📖 Contenido MVP

### Libros Priorizados:
1. **Ezequiel** (48 capítulos) — Profético, exilio babilónico
2. **Salmos seleccionados** (15-20) — Poético, contextos variados
3. **Jonás** (4 capítulos) — Narrativo, tipología

### Por cada capítulo:
- Contexto histórico detallado (300+ palabras)
- Análisis estructural
- 5-10 palabras clave con etimología
- 10-20 conexiones bíblicas
- 8-12 preguntas reflexivas

---

## 🎨 Características Principales

### 1. Contexto Histórico por Capítulo
Cada capítulo abre con:
- Fecha exacta y evento histórico
- Imperio dominante
- Situación política
- Estado espiritual del pueblo
- Figuras clave (profetas, reyes)

### 2. Timeline Interactiva (planificada — no implementada)
Visualización cronológica futura que mostrará:
- Reyes, profetas y eventos superpuestos
- Capítulos anclados a momentos históricos
- Filtros por periodo, imperio, figura

### 3. Flujo de Estudio Pedagógico
```
📜 Contexto histórico
   ↓
📖 Lectura bíblica
   ↓
🔍 Análisis estructural
   ↓
🧠 Etimología y palabras clave
   ↓
🔗 Conexiones bíblicas
   ↓
🤔 Preguntas reflexivas
```

### 4. Bilingüismo Completo
- Interfaz en español/inglés
- Todo el contenido traducido
- Cambio instantáneo
